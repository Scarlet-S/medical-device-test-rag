# 项目原创测试实践文档

本目录用于补充监管指导原则没有展开到具体执行层的医疗器械控制软件测试方法。

## 使用边界

- 文档类型：项目原创工程实践。
- 适用目的：测试策划、用例设计、执行记录、证据整理和 RAG 场景问答。
- 不属于法规、强制性标准、监管指导原则或企业质量体系程序。
- 文中的“建议”“可采用”“宜”均为项目方法，不应改写为监管强制要求。
- 涉及中国注册、体系核查或现场检查结论时，应优先检索 DOC001-DOC008 的中国官方原文。
- 涉及 FDA 要求时，应检索 DOC009-DOC011，并明确美国监管语境。
