# Source Documents

This directory stores the original documents used to build the medical device software testing knowledge base.

Document categories include:

- Regulations and standards
- Software lifecycle
- Risk management
- Requirements and traceability
- Software testing
- Access control and security
- Anomaly and fault handling
- Change and regression testing
- Test templates and cases

Original documents are not committed to GitHub because of file size, copyright, or licensing restrictions.

The metadata and source information of each document are recorded in:

`data/catalog/document_catalog.csv`
