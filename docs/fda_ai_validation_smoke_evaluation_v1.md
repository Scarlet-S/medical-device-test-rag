## 5. 工程修复

本轮验证发现并修复两类批量工程问题：

1. RAGFlow 已接受上传但 HTTP 连接提前关闭时，客户端会按确定性文件名
   对账远端状态，避免误判失败和重复上传。
2. Windows 控制台统一使用 UTF-8 输出，避免含 `®`、`™` 等器械名称
   导致批量评测中断。
