# v1.4.0：FDA AI 真实产品验证案例库

v1.4.0 将批量文档摄取管线应用于真实公开语料，建立独立的 FDA AI 医疗器械
验证案例层，并完成从离线解析、增量索引到冻结容量回归的端到端验收。

## 主要更新

- 从 FDA AI-enabled Medical Devices 官方清单确定性选择并下载 300 份公开
  510(k) 决定摘要，覆盖 15 个专业面板。
- 使用 Docling 完成 PDF 结构化转录，使用 LangChain 执行标题感知与递归切片，
  结合 SHA-256 去重、SQLite 状态管理和 ProcessPool 有限并发。
- 增加 FDA 模板噪声、乱码、低信息片段和文档内重复过滤；300/300 文档通过
  离线质量验收，共生成 17,482 个本地审计切片。
- 通过 RAGFlow API 全量写入独立案例库；300/300 文档状态为 `DONE`，生成
  4,791 个在线检索切片。
- 验证失败断点恢复：Embedding 连接中断后仅重试失败文档，复用本地结构化
  结果和远端文档，未重复处理已完成项目。
- 建立并冻结 20 道 FDA 案例评测题，覆盖监管分类、预期用途、性能验证证据
  以及软件和算法功能。

## 最终评测

- 执行成功率：20/20（100%）
- Top-1 / Top-3 命中率：100% / 100%
- 精确文件 Top-1 / Top-3 命中率：100% / 100%
- 引用正确率：100%
- 回答准确度：37/40（92.5%）
- 幻觉率：0%

冻结题包含 510(k) 编号或器械名称，主要验证大规模同类文档中的精确文件定位
和证据问答能力，不等同于无显式标识的跨文档盲测。
