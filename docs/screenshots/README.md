### 检索测试

```text
设计开发验证或确认的工作范围和程度应如何确定？
```

预期优先命中DOC005第4.5.4条。

### 带引用问答

```text
注册质量管理体系现场核查可能形成哪四种结论？
```

预期回答“通过核查、未通过核查、整改后通过核查、整改后未通过核查”，并引用DOC005第5.2节。

## 截图要求

1. 使用 `Win + Shift + S` 截取必要区域。
2. 保留页面名称、关键设置或指标，裁掉无关区域。
3. 不使用聊天软件压缩后的模糊图片。
4. 建议宽度不低于1600像素。
5. 同一页面只保留一张信息最完整的截图。
6. 截图完成后检查文字是否可读、是否包含密钥或个人信息。
