# 检索权重参数对比实验

## 实验目标

比较向量相似度与全文检索的不同权重组合，选择兼顾严格来源命中和等价来源命中的最终配置。

## 固定参数

除向量与全文权重外，其余参数保持一致：

| 参数 | 配置 |
|---|---|
| 相似度阈值 | 0.2 |
| Top N | 8 |
| Rerank | qwen3-rerank |
| 题目数量 | 50 |
| 会话策略 | 每题独立会话 |

## 最终参数

选择配置 B：

```text
相似度阈值：0.2
vector：0.50
full-text：0.50
Top N：8
Rerank：qwen3-rerank
```

选择理由：

1. B 与 C 的严格 Top-1、Top-3 相同。
2. B 的可接受 Top-1 为 88%，比 C 高 2 个百分点。
3. 相比原基线，B 的严格 Top-1 提升 8 个百分点，严格 Top-3 提升 4 个百分点。
4. B 在关键词匹配与语义匹配之间更均衡，没有继续提高向量权重所带来的 Q006、Q033 退步。

## 局限性

- RAG回答和LLM裁判均具有一定随机性，单次实验不能替代重复实验和人工复核。
- DOC003与DOC004存在大量语义相同或近似条款，因此同时报告严格来源指标和可接受等价来源指标。
- 人工标签应绑定具体回答实例；参数变化后生成的新回答不能直接沿用旧回答标签。
- 自动裁判用于批量初评和定位异常题，最终争议仍由人工依据标准答案和实际引用证据裁决。
